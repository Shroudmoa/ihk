## 10.2 User CAL vs. Device CAL

| Typ | Wann sinnvoll |
|-----|---------------|
| **User CAL** | Pro **Benutzer**. Sinnvoll bei **Roaming** (Mitarbeiter nutzen mehrere Geräte) oder wenn es **mehr Geräte als User** gibt. Anzahl Geräte egal. |
| **Device CAL** | Pro **Gerät**. Sinnvoll, wenn **mehrere User ein Gerät** teilen (Schichtbetrieb, Terminals). Anzahl User egal. |

**Merksatz:** Mehr Geräte als Leute → User CAL. Mehr Leute als Geräte →
Device CAL.

## 10.3 Weitere Lizenzbegriffe (allgemein)

- **OEM:** an Hardware gebunden
- **Volume/VLK:** Mengenlizenz (Kirche, Schule, Firma)
- **Open Source:** frei nutzbar (Lizenzbedingungen beachten, z. B. GPL)
- **Trial/Freeware/Shareware:** Test-/Gratis-Varianten

## 10.4 Update vs. Upgrade (2023W, 2025S)

| Begriff | Bedeutung | Kosten/Lizenz |
|---|---|---|
| **Update** | Fehlerbehebung/kleinere Verbesserung **derselben Version** (z. B. Patch, Service Pack) | In der Regel **kostenlos**, bestehende Lizenz gilt weiter |
| **Upgrade** | Wechsel auf eine **neue Hauptversion** mit neuem Funktionsumfang | In der Regel **kostenpflichtig**, oft neue/zusätzliche Lizenz nötig |

**Merksatz:** Update = "Reparatur/Pflege" der vorhandenen Version (gratis).
Upgrade = "Aufstieg" auf eine neue Version (kostet extra, ggf. neue
Lizenzbedingungen).

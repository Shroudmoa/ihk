# Berechnung des Arbeitnehmeranteils zur gesetzlichen Krankenversicherung (GKV)

**Gegebene Werte:**
- Bruttogehalt: 4.200,00 EUR
- Allgemeiner Beitragssatz: 14,6 %
- Zusatzbeitrag (Arbeitnehmeranteil): 2,4 %

**Wichtige IHK-Regel (Parität):**
Der Gesamtbeitrag zur GKV wird grundsätzlich **hälftig** zwischen Arbeitgeber und Arbeitnehmer geteilt (§ 249 SGB V). Das gilt für den allgemeinen Beitragssatz. Den **Zusatzbeitrag** trägt seit 2019 ebenfalls der Arbeitnehmer allein (früher hälftig).

**Berechnungsschritte:**

1. **Allgemeiner Beitragssatz (Arbeitnehmeranteil):**
   14,6 % / 2 = **7,3 %**
   
2. **Zusatzbeitrag (Arbeitnehmeranteil):**
   Der Zusatzbeitrag wird vom Arbeitnehmer **allein** getragen: **2,4 %**

3. **Gesamter Arbeitnehmeranteil in Prozent:**
   7,3 % + 2,4 % = **9,7 %**

4. **Beitrag in Euro:**
   4.200,00 EUR × 9,7 % = **407,40 EUR**

**Ergebnis für das Kästchen:**
**407,40** (oder 407,40 EUR)

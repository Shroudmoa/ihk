# Subnetting IPv4 & IPv6

## IPv4 Subnetting

- **CIDR**: Classless Inter-Domain Routing (/24, /26, ...)
- **Netzanteil / Hostanteil**
- **2^n - 2** nutzbare Hosts (bei klassischem Subnetting)

## IPv6

- **128 Bit** Adressen
- **SLAAC**: Stateless Address Autoconfiguration
- **/64** ist typischer Subnetzblock

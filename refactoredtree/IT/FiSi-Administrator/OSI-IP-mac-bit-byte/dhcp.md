# DHCP (Dynamic Host Configuration Protocol)

## DORA-Prozess

1. **Discover** - Client sucht DHCP-Server
2. **Offer** - Server bietet IP-Adresse an
3. **Request** - Client fordert angebotene Adresse an
4. **Acknowledge** - Server bestätigt Zuweisung

## Wichtige Begriffe

- **Lease**: Leihzeit der IP-Adresse
- **DHCP-Relay**: Weiterleitung von DHCP-Anfragen über Router
- **DHCP-Snooping**: Schutz vor Rogue-DHCP-Servern

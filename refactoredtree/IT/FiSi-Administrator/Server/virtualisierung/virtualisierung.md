# Virtualisierung

## Definition

Virtualisierung ist die Abstraktion von Hardwareressourcen, um mehrere virtuelle Systeme auf einem physischen Host betreiben zu können.

## Vorteile

- Bessere Auslastung der Hardware
- Geringerer Energieverbrauch
- Einfachere Bereitstellung
- Hohe Flexibilität

## Nachteile

- Single Point of Failure ohne Redundanz
- Höhere Komplexität
- Sicherheitsrisiken bei Fehlkonfiguration

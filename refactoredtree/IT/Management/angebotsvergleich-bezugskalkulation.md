# Angebotsvergleich und Bezugskalkulation

## In 30 Sekunden

- Beim **quantitativen Angebotsvergleich** werden alle Angebote auf denselben **Bezugspreis (Einstandspreis)** umgerechnet.
- Schema: **Listeneinkaufspreis − Rabatt = Zieleinkaufspreis − Skonto = Bareinkaufspreis + Bezugskosten = Bezugspreis**.
- **Rabatt** = Preisnachlass (Mengen-, Treue-, Sonderrabatt); **Skonto** = Nachlass für Zahlung innerhalb einer Frist.
- Rabatt und Skonto sind **Prozente vom jeweils vorherigen Betrag**, nicht vom Listenpreis.
- Neben dem Preis zählen **qualitative Kriterien**: Lieferzeit, Garantie, Support, Zuverlässigkeit, Zahlungsbedingungen → [Nutzwertanalyse](nutzwertanalyse.md).
- Umsatzsteuer: Für vorsteuerabzugsberechtigte Unternehmen wird **netto** verglichen.

## Kernwissen

### Schema der Bezugskalkulation

| Schritt | Rechnung |
|---|---|
| Listeneinkaufspreis (Menge × Stückpreis) | |
| − Lieferantenrabatt (% vom Listenpreis) | |
| **= Zieleinkaufspreis** | |
| − Lieferantenskonto (% vom Zieleinkaufspreis) | |
| **= Bareinkaufspreis** | |
| + Bezugskosten (Versand, Verpackung, Versicherung, Installation, Zoll) | |
| **= Bezugspreis / Einstandspreis** | |

### Rechenbeispiel: 20 Notebooks

| | Anbieter A | Anbieter B | Anbieter C |
|---|---:|---:|---:|
| Stückpreis netto | 950,00 € | 1.020,00 € | 900,00 € |
| Rabatt | 5 % | 12 % | – |
| Skonto | 2 % (10 Tage) | 3 % (14 Tage) | – |
| Bezugskosten | 150,00 € | frei Haus | 380,00 € |

**Anbieter A**

| Schritt | Betrag |
|---|---:|
| Listeneinkaufspreis 20 × 950 € | 19.000,00 € |
| − 5 % Rabatt | − 950,00 € |
| = Zieleinkaufspreis | 18.050,00 € |
| − 2 % Skonto | − 361,00 € |
| = Bareinkaufspreis | 17.689,00 € |
| + Bezugskosten | 150,00 € |
| **= Bezugspreis** | **17.839,00 €** |

**Anbieter B**

| Schritt | Betrag |
|---|---:|
| Listeneinkaufspreis 20 × 1.020 € | 20.400,00 € |
| − 12 % Rabatt | − 2.448,00 € |
| = Zieleinkaufspreis | 17.952,00 € |
| − 3 % Skonto | − 538,56 € |
| = Bareinkaufspreis | 17.413,44 € |
| + Bezugskosten | 0,00 € |
| **= Bezugspreis** | **17.413,44 €** |

**Anbieter C**

| Schritt | Betrag |
|---|---:|
| Listeneinkaufspreis 20 × 900 € | 18.000,00 € |
| + Bezugskosten | 380,00 € |
| **= Bezugspreis** | **18.380,00 €** |

**Ergebnis:** B ist mit 17.413,44 € am günstigsten, obwohl der Listenpreis am höchsten ist. C mit dem niedrigsten Stückpreis ist am teuersten. Pro Gerät: B = 870,67 €.

### Lohnt sich Skonto? (Skontosatz als Jahreszins)

Zahlungsbedingung: "2 % Skonto bei Zahlung innerhalb von 10 Tagen, sonst 30 Tage netto." Wer das Skonto nicht nutzt, "leiht" sich das Geld 20 Tage lang für 2 %.

`effektiver Jahreszins ≈ Skontosatz × 360 ÷ (Zahlungsziel − Skontofrist) = 2 % × 360 ÷ 20 = 36 %`

Selbst ein Kontokorrentkredit mit 12 % Zins ist günstiger – Skonto sollte fast immer genutzt werden.

### Qualitative Kriterien beim Angebotsvergleich

- Lieferzeit und Liefertreue
- Garantie und Gewährleistung (Vor-Ort-Service, Next Business Day)
- Qualität, Zertifizierungen, Energieeffizienz
- Kompatibilität mit vorhandener Infrastruktur
- Zuverlässigkeit und Referenzen des Lieferanten
- Zahlungsbedingungen, Rückgaberecht, Mindestabnahme

### Bezugsquellen ermitteln

Herstellerseiten, Großhändler/Distributoren, Ausschreibungsplattformen, Messen, Branchenverzeichnisse, bestehende Lieferantendatei; bei öffentlichen Auftraggebern Vergaberecht beachten.

## Prüfungsfrage

**Frage:** Für 10 Switches liegen zwei Angebote vor. Anbieter 1: 480 € pro Stück, 10 % Rabatt, 2 % Skonto, Versand 60 €. Anbieter 2: 450 € pro Stück, kein Rabatt, 3 % Skonto, Versand 25 €. Ermitteln Sie die Bezugspreise und entscheiden Sie unter Angabe eines weiteren Kriteriums.

**Musterantwort:**
- Anbieter 1: 4.800,00 € − 480,00 € (10 %) = 4.320,00 €; − 86,40 € (2 %) = 4.233,60 €; + 60,00 € = **4.293,60 €**
- Anbieter 2: 4.500,00 €; − 135,00 € (3 %) = 4.365,00 €; + 25,00 € = **4.390,00 €**

Anbieter 1 ist um 96,40 € günstiger. Vor der Entscheidung sollten qualitative Kriterien geprüft werden, z. B. die **Lieferzeit**: Muss das Projekt in zwei Wochen starten und kann nur Anbieter 2 sofort liefern, kann Anbieter 2 trotz höherem Preis die bessere Wahl sein.

## Falle

- **Skonto vom Listenpreis rechnen:** Skonto bezieht sich auf den Zieleinkaufspreis (nach Rabatt).
- **Rabatt und Skonto addieren:** 10 % + 2 % sind nicht 12 % vom Listenpreis.
- **Bezugskosten vergessen** oder vom Preis abziehen statt aufschlagen.
- **Brutto und netto mischen:** Entweder alle Angebote netto oder alle brutto vergleichen.
- **Nur den Preis entscheiden lassen:** Die Aufgabe verlangt oft eine Begründung mit weiteren Kriterien.

## Merksatz

**"Liste minus Rabatt = Ziel, Ziel minus Skonto = Bar, Bar plus Bezug = Einstand."**
